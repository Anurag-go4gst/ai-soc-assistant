# Intent-advisor value, O5c live trigger, live scorecard (residuals closure)

## Evidence base (measured 2026-07-04, ai_trace_runs n=1279)

- `intent_shadow_classifier`: 454 calls — 267 completed (avg **44.3s**), 111 timed_out (avg 97.9s, pre-bound), 76 dropped. Under the current 25s T2 bound on the 6 tok/s VPS the hop mostly times out.
- Downstream actuation: `apply_advisory_promotion` → **0 promotions ever** (`llm_promoted_with_registry_validation` absent from all 1279 runs); route-adjudication SPL-authoring rescue (`source=llm_advisory`) → **0 ever**; remaining consumers are draft-preview hints + trace display (cosmetic).
- Only 52/910 adjudicated advisories were ever `accepted` (5.7%).
- Structural: promotion REQUIRES the LLM candidate to appear in `semantic_candidates(query)` (or semantic empty) — the LLM can only confirm/pick among what the word-token cosine index already found. Its unique value is precision/abstain on an ambiguous semantic band, not recall.
- Governance anchor kept: `semantic_question_index` docstring — semantic candidates are **never silently landed**; LLM confirmation is the deliberate double-evidence gate. This plan does NOT introduce semantic-only auto-promotion.
